Aturan Penamaan File Dokumen yang Baik untuk Arsip Digital

Diterbitkan 20 Oktober 2026 · Tim SAD

Nama file sering dianggap sepele, padahal inilah petunjuk pertama saat mencari dokumen. File bernama scan001 atau dokumen baru final2 tidak memberi informasi apa pun. Dengan aturan penamaan yang konsisten, ribuan file tetap mudah dikelola.

Komponen nama file yang disarankan

  • Tanggal dalam format tahun-bulan-tanggal, misalnya 2026-10-20, agar file otomatis terurut menurut waktu.
  • Jenis dokumen, misalnya Surat Keluar, Notulen, atau SK.
  • Nomor register atau nomor surat jika ada.
  • Perihal singkat yang menjelaskan isi dokumen.

Contoh: 2026-10-20 Surat Keluar 045 Undangan Rapat Komite. Dari nama itu saja, siapa pun sudah tahu isi dan waktunya.

Hal yang sebaiknya dihindari

  • Karakter khusus seperti garis miring, tanda tanya, atau tanda bintang karena dapat menimbulkan masalah di sebagian sistem.
  • Nama yang terlalu panjang, usahakan di bawah sekitar seratus karakter.
  • Kata yang ambigu seperti final, baru, atau revisi tanpa keterangan tanggal.
  • Singkatan yang hanya dipahami oleh satu orang.

Menangani versi dokumen

Jika dokumen mengalami revisi, tambahkan nomor versi di akhir nama, misalnya v1, v2, dan v3. Simpan versi akhir yang resmi dengan penanda yang jelas, dan jangan menimpa versi lama jika masih diperlukan sebagai bukti proses.

Biasakan sejak awal

Aturan penamaan paling efektif jika disepakati bersama dan ditulis dalam satu halaman panduan internal. Bagikan contoh yang benar dan salah kepada seluruh petugas. Saat mengunggah dokumen ke aplikasi arsip, isi kolom nama atau keterangan dengan pola yang sama. Kebiasaan kecil ini akan sangat terasa manfaatnya ketika jumlah dokumen sudah mencapai ribuan.

Contoh perbandingan nama file

Bandingkan dua nama berikut. Nama pertama: scan_baru2.pdf. Nama kedua: 2026-09-14 Notulen Rapat Dewan Guru Semester Ganjil.pdf. Nama pertama tidak memberi petunjuk apa pun dan membuat petugas harus membuka file satu per satu. Nama kedua langsung menjelaskan jenis, topik, dan waktunya, serta otomatis terurut di dalam folder.

Pertanyaan yang sering muncul

Perlukah memakai huruf besar semua? Tidak. Gunakan huruf kapital di awal kata seperti kalimat biasa agar mudah dibaca. Bolehkah memakai spasi? Boleh, selama aplikasi yang digunakan mendukungnya. Jika file akan dibagikan lewat tautan web, garis bawah atau tanda hubung lebih aman sebagai pengganti spasi.

Bagaimana jika nama file menjadi terlalu panjang? Pindahkan sebagian informasi ke folder. Misalnya jenis dokumen dan tahun cukup berada pada nama folder, sehingga nama file bisa lebih ringkas.
